# Симуляция OUTPOST

MisDay — условные игровые сутки: 300 реальных секунд на скорости 1×. Кампания завершается после 30 MisDay; пауза и скорости 2× и 5× поддерживаются методом `GameManager.set_speed`. Отображение: `MISSION DAY 01 / 30`. Это игровая шкала, не лунные сутки.

`radiation_level` — условный индекс от 0 до 100; `crew_dose` — накопленная условная доза, не измерение в мЗв. Уровни, длительности и преобразование индекса в дозу придуманы для игры, не являются данными NASA. `CrewHabitat` уменьшает дозу при `protected_mode = true`. `ScienceDome` даёт `research`, когда экипаж жив и жизнеобеспечение работает. Каждый непосредственный дочерний узел `LunarBase` с именем `SolarArray*` добавляет мощность. Отключение солнечной генерации сохраняет работу аккумулятора.

Локальные сценарии запускаются через `BaseSimulation.start_scenario("solar_flare")`, `start_scenario("cme_warning")` или `start_scenario("sep_event")`. CME сначала даёт предупреждение на 30 игровых минут, затем опасная фаза длится 60 минут; другие сценарии длятся 60 минут. Одновременно работает один сценарий. Автоматического запуска сценариев и кнопок запуска нет.

`donki_adapter.gd` — необязательный независимый адаптер. Добавьте его узлом и вызовите `refresh()` при необходимости; игра не делает запросы сама. Ключ читается только из переменной окружения `NASA_API_KEY`. Адаптер запрашивает FLR, CME и SEP за 1–30 июня 2026, сохраняет успешный полный результат в `user://donki_2026_06.json` и использует кэш либо пустую заглушку при отсутствии ключа, сети или ошибке. Эти исторические записи не запускают игровые сценарии автоматически и не превращаются в игровые уровни радиации. Источник форматов API: https://api.nasa.gov/.
